## 三、决定延迟的不是机房，是回程线路：CN2 / 9929 / CMIN2 一次讲明白

这块是全文最该认真看的部分，因为它直接决定你花的钱值不值。

大陆到香港（以及日本、新加坡）的网络，本质上是三家运营商各自为政：电信、联通、移动。普通 BGP 线路走的是各家的大众骨干网，晚高峰一挤就废。所谓"精品回程"，就是让数据包**从香港返回大陆时，走各家专门优化过的高端线路**。具体三个名字记住就行：

- **CN2（AS4809 / 163）**：电信的精品网，分 CN2 GT 和 CN2 GIA。GIA 是真·旗舰，延迟低、晚高峰稳，电信用户用它基本就是丝滑。
- **9929（AS4837 / CUII）**：联通的高端线路，俗称"联通 9929"。联通用户走这条，比普通 4837 强一大截。
- **CMIN2（CMI / AS58807）**：移动的国际精品网，移动用户走这条，体验对得起"移动优化"这四个字。

关键点来了：一条线路好不算好，**三网全优化才是真·大陆低延迟**。只优化电信的、只优化移动的，到了晚高峰另外两家的用户照样抓狂。GoMami 把"三网精品回程"作为主打，意思是电信走 CN2、联通走 9929、移动走 CMIN2，去程主干走高 Q 路由。这就是它敢标 RTT < 50ms 的底气。

> 顺带提一句，判断一家港机到底走没走精品线路，别只看商家自吹，自己上手测：从大陆不同运营商网络 `ping` 服务器 IP、跑 `mtr` 看回程路由跳数和 AS 号。看到 4809、4837、58807 这些 AS 号出现，基本就是对的。
